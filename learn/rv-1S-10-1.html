THEME 01

무리식이 실수가 되는 조건

▶ 0:50▶ 2:01

근호 안에 변수가 있으면 무리식. 실수가 되려면 근호 안 \ge 0.

판서 — 두 가지 조건

  1. \sqrt{A}가 실수 \iff A\ge 0
  2. 분모에 있는 \dfrac{1}{\sqrt{A}}는 0도 안 된다 \iff A>0
  3. 예) \sqrt{x+3}+\dfrac{1}{\sqrt{2-x}} → x+3\ge 0, 2-x>0

"모든 실수 x에 대하여" 실수

  1. kx^{2}-4kx+9\ge 0이 항상 성립해야 한다
  2. 판별식부터 쓰지 말고 k 분류 먼저
  3. k>0이고 \dfrac{D}{4}\le 0 → 떠 있거나 접한다
  4. k=0이면 9\ge 0 → 성립! 빠뜨리지 않기
수업 포인트범위가 주어지면 근과 계수의 관계로 바로: 두 근의 합·곱에서 a,\ b를 읽는다.

THEME 02

무리식의 사칙연산

▶ 5:39▶ 8:34

제곱근의 성질 두 가지만 조심하고, 통분은 공통인수로.

판서 — 제곱근의 성질

  1. \sqrt{a^{2}}=|a|  a\ge 0이면 a, a<0이면 -a
  2. "\pm a"가 아니다. \sqrt{5^{2}}=\sqrt{(-5)^{2}}=5
  3. \sqrt{a}\sqrt{b}=\sqrt{ab}  예외: a<0,\ b<0이면 -\sqrt{ab}
  4. \dfrac{\sqrt{a}}{\sqrt{b}}=\sqrt{\dfrac{a}{b}}  예외: a>0,\ b<0이면 -\sqrt{\dfrac{a}{b}}

통분 · 정수 부분

  1. a-b=(\sqrt{a})^{2}-(\sqrt{b})^{2}로 보면 공통인수가 보인다
  2. n^{2}<n^{2}+2n<(n+1)^{2} → \sqrt{n^{2}+2n}의 정수 부분은 n
  3. 소수 부분 =\sqrt{n^{2}+2n}-n → 유리화하면 \dfrac{2n}{\sqrt{n^{2}+2n}+n}
수업 포인트곱해서 통분하지 말고 최소공배수(공통인수)로. 식이 커지면 정리가 안 된다.

THEME 03

분모의 유리화

▶ 13:22

켤레를 곱해 합차로 근호를 없앤다. 결과만 바로 쓰는 연습.

판서 — 암산으로 줄이기

  1. \dfrac{1}{\sqrt{a}+\sqrt{b}}=\dfrac{\sqrt{a}-\sqrt{b}}{a-b}  분모는 제곱끼리 빼기만
  2. 연쇄 소거: \dfrac{1}{\sqrt{n}+\sqrt{n+1}}=\sqrt{n+1}-\sqrt{n} → 커지는 방향으로 써야 지워지는 게 보인다
  3. 공통인수 -1은 앞으로 묶고 계산
  4. x,\ y가 켤레 → x+y, xy부터 (켤레는 합과 곱이 쉽다)
  5. (\sqrt{x}-\sqrt{y})^{2}를 구했으면 부호 확인: y>x이면 \sqrt{x}-\sqrt{y}<0
수업 포인트켤레를 한 줄씩 다 적지 마라. 처음엔 써도 되지만 시험 전까지 결과만 쓰는 쪽으로 업그레이드.

THEME 04

무리함수의 그래프 · 정의역과 치역

▶ 22:10▶ 26:14▶ 33:08

기본형 y=\pm\sqrt{ax}는 네 가지. 시작점과 부호 두 개면 그래프가 끝난다.

CONCEPT 02 · 기본형 네 가지

  1. y=\sqrt{x},\ \sqrt{-x},\ -\sqrt{-x},\ -\sqrt{x}
  2. x 앞 부호 → 근호 앞 부호 순서로 읽으면 뻗는 사분면 (+,+)=1 · (−,+)=2 · (−,−)=3 · (+,−)=4
  3. y=\sqrt{x}는 y=x^{2}와 역함수 관계 (눕힌 포물선의 반쪽)
  4. 정의역: 근호 안 \ge 0 · 치역: 근호 앞 부호

|a|와 평행이동

  1. |a|가 커질수록 축에서 멀어진다
  2. y=\pm\sqrt{a(x-p)}+q → 시작점 (p,\,q)
  3. 정의역·치역은 시작점에서 바로 읽기

예제 · y=-\sqrt{4-2x}+3

  1. 시작점: 근호 안 =0 → x=2, 바깥 상수 3 → (2,\,3)
  2. 부호 (-,-) → 3사분면 방향
  3. 정의역 x\le 2, 치역 y\le 3
  4. 식으로 읽어도 된다: \sqrt{4-2x}\ge 0 → -\sqrt{4-2x}+3\le 3
수업 포인트3·4사분면 방향이라고 직선이나 꺾인 선으로 그리지 말 것. 눕힌 이차함수의 조각이다.

THEME 06

그래프가 지나는 사분면

▶ 43:21

예제 · y=-\sqrt{x+4}+1

  1. 시작점 (-4,\,1) · 부호 (+,-) → 4사분면 방향

  3. 지나는 사분면: 제2, 3, 4사분면
  4. 계수 부호를 묻는 문제는 유리함수 그래프에서 부호를 먼저 읽고 넘어온다

무리함수 y=\sqrt{-3x+a}+5의 그래프가 다음 그림과 같을 때, 두 상수 a, b에 대하여 ab의 값은?

①42②45③48④51⑤54
핵심 시작점 (3,\,b)에서 근호 안이 0 — a=9, b=5.
정답 ②
함수 y=\sqrt{-3x}의 그래프를 x축의 방향으로 \dfrac{a}{3}만큼, y축의 방향으로 b만큼 평행이동시킨 것이다.
y=\sqrt{-3\left(x-\dfrac{a}{3}\right)}+b=\sqrt{-3x+a}+b
위 함수가 y=\sqrt{-3x+a}+5와 같아야 하므로 b=5
또한 함수 y=\sqrt{-3x+a}+5의 그래프가 점 (3,\,b),
즉 (3,\,5)를 지나므로
5=\sqrt{-9+a}+5\;\therefore \;a=9
\therefore \;ab=9\times 5=45
