지난 시간 — 기본형과 일반형

▶ 0:00▶ 1:55

모든 무리함수는 y=\pm\sqrt{ax}를 평행이동한 것. 시작점과 부호 두 개.

판서

  1. 표준형 y=\pm\sqrt{a(x-p)}+q → 시작점 (p,\,q), 정의역·치역은 시작점에서
  2. 일반형 y=a\sqrt{bx+c}+d → 근호 앞 수는 안으로: x의 계수는 a^{2}b
  3. 예) y=-4\sqrt{3-x}+1 → x의 계수 -16, 3사분면 방향
  4. 유리함수와 달리 합성함수 유형은 없다 (근호 안에 근호가 들어가니까)
수업 포인트그래프는 눕힌 이차함수의 조각. 직선이나 꺾인 선으로 그리지 말 것.
THEME 10

그래프와 직선의 위치 관계

▶ 3:51▶ 5:37▶ 9:22

경계는 두 개 — 시작점을 지날 때와 접할 때(D=0).

예제 · y=\sqrt{x-1}과 y=x+k

  1. 그래프는 통통하게 크게 그린다
  2. 기울기 고정 직선을 내리면: 안 만남 → 접함 → 두 점 → (시작점 지나고) → 한 점
  3. ① 시작점 (1,\,0)을 지날 때 k=-1 → 아직 두 점 (등호 포함)
  4. ② 접할 때: x^{2}+(2k-1)x+k^{2}+1=0, D=-4k-3=0 → k=-\dfrac{3}{4} (한 점, 미포함)
  5. 두 점에서 만나는 범위: -1\le k<-\dfrac{3}{4}

판별식의 함정

  1. \sqrt{x}=x+k를 제곱하면 y=-\sqrt{x}와의 교점까지 섞인다
  2. 그래서 "두 점 \iff D>0"은 틀린다 — 부등호로 쓰지 말고 경계만 찾는다
  3. 한 점에서 만난다 ≠ 접한다 (시작점을 지나며 한 점에서 만날 수도)
  4. 점이 시작점과 같은 세로선 너머로 가면 접하는 경우가 없다 → 경계는 시작점 하나

이차함수·무리함수가 역함수 관계일 때

  1. 꼭짓점과 시작점이 y=x에 대하여 대칭 + 계수가 역수 → 역함수 관계
  2. 증가하면 둘의 교점 = 한쪽과 y=x의 교점
  3. 이차함수 쪽은 정의역이 제한돼 있어 판별식만으로는 안 된다 → 무리함수와 y=x로 경계 두 개
수업 포인트헷갈리면 시작점을 지날 때와 접할 때를 둘 다 구해 비교한다.

THEME 11

역함수

▶ 31:55▶ 34:00▶ 38:37

시작점 (p,\,q) → 꼭짓점 (q,\,p), 계수는 역수. 정의역을 꼭 쓴다.

판서 — 바로 쓰기

  1. y=\sqrt{a(x-p)}+q → y=\dfrac{1}{a}(x-q)^{2}+p
  2. 정의역 = 원래 함수의 치역: 근호 앞이 +면 x\ge q, -면 x\le q
  3. 예) f(x)=\sqrt{2x-4}+1 → f^{-1}(x)=\dfrac{1}{2}(x-1)^{2}+2\ (x\ge 1)
  4. 값 하나만 필요하면 f^{-1}(b)=a\iff f(a)=b — 역함수를 만들지 않는다

두 교점 사이의 거리

  1. f와 f^{-1}의 교점은 (증가하면) y=x 위 → (\alpha,\,\alpha), (\beta,\,\beta)
  2. 기울기 1이므로 거리 =\sqrt{2}(\beta-\alpha) — 좌표를 다 구하지 않는다
  3. 인수분해가 안 되면 근과 계수의 관계로 \beta-\alpha
  4. 감소하는 함수는 y=x 밖에서도 만난다 (예: (0,\,3), (3,\,0))
수업 포인트"끝났죠? 안 끝났어요" — 역함수 식 뒤에 정의역이 없으면 틀린 답.

THEME 12

그래프의 활용

▶ 46:42

휘어진 정도가 같은 곡선 사이 넓이는 잘라 옮겨 붙이기.

예제 · y=\sqrt{x}, y=\sqrt{x}+2, x=0, x=4

  1. 튀어나온 부분을 빈 곳에 채우면 직사각형 → 4\times 2=8
  2. 딱 맞지 않으면 곡선 부분만 회 떠서 옮긴다 → 평행사변형 (밑변 × 높이)
  3. 삼각형 넓이 최대 → 밑변과 평행한 접선일 때 (D=0)
  4. 넓이의 비 → 높이의 비 → 함숫값의 비로 식을 세운다
수업 포인트평행사변형 넓이 = 밑변 × 높이. 신발끈 공식보다 잘라 붙이기가 빠르다.
